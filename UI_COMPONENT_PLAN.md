# Tally Connector — UI Component Plan

**Compliance:** UI_INTERFACE_STANDARD.md

## Структура панели
- **Левый сайдбар:** Форма подключения/настроек, растянутая на всю ширину контейнера. Все инпуты с явными лейблами. Никакого дублирования текста из модалок.
- **Центральная рабочая зона:**
  - Карточки метрик и статуса подключения (Connection Health, активные сущности).
  - Основная таблица сущностей (формы (/forms)).
  - Панель действий и быстрых фильтров.
- **Модальные окна:** Диалоги подтверждения для любых деструктивных или публикующих действий.
